What each module owns

TypeScript only, with English names. The site is a few ES modules bundled into one script; the tooling runs on Node 26 straight from its .ts files. One file of types describes the data for both.

ModuleOwnsTested by
src/types.tsThe interfaces of the referential, a schema next to each, and the list of data files. The schema type makes the compiler fail if a schema misses a key, adds one, or gets an optional or nullable flag wrong. Holds the Parliament types, with the API's own field names, and the function keys.tsc; used by check
src/site/referential.tsThe data as the site sees it: imports data/*.json at build time, the Confederation level, the covered cantons (any canton with parties), URL lookup by id, the Parliament's data. It is the one place that keeps voters to verified links: unverified state sites and tools are left out, an unverified party URL is hidden so its card offers a search.check guarantees the shapes it trusts and that every entry linked by id is verified; parity run
src/site/links.tsThe ids of the state sites and tools the site links to by name (menu shortcuts, item tabs, aids). No URL in code.check fails if an id is missing or has no URL
src/site/app.tsRouting and address, remembered territory, menu, territory sheet and tile map, parties half-circle and card (the presidency, the federal lines of a CH party, the cantonal lines of a section, the sources under the card), decision aids, official sites with search. Exposes the current territory and a render hook.Parity run; card text read back in headless Chromium; tsc
src/site/institutions.tsThe page "Qui gouverne et qui siège": Federal Council list, the National Council half-circle proportional to its seats, the Council of States bar, legends whose lines open a group's members (one click handler for the page); for a canton, its government, its Grand Conseil half-circle, its members in Bern; the source blocks. Re-renders when the territory changes.Screens captured at phone width and read against the data; tsc
src/site/parliament.tsPure reading of the generated file: members of a chamber, Federal Council members and their own department, seats grouped by site party from left to right with "Autres", a party's main and regional labels, the members of one seat group by canton then by name. No DOM and no data import, so the check uses it too.tools/parliament.test.ts; check runs on it; tsc in both configurations
src/site/cantonal-parliaments.tsPure reading of the generated OFS file: a canton's row, its election year and total, seats per OFS column with the party it maps to, the groups of the Grand Conseil half-circle (seven B2 colours, the eighth for the largest canton-only party, "Autres"), the OFS note naming "Autres". Shared by the site and the check.tools/cantonal-parliaments.test.ts
src/site/cantonal-standing.tsThe lines of a cantonal party's card: government count, Grand Conseil seats with the year, share of the canton's federal delegation (a canton-only party matched by its abbreviation); one source link per site. Pure.tools/cantonal-standing.test.ts, on all 42 sections of the real data
src/site/presidency.tsThe "Présidence" line and its source: names joined the French way ("A, B et C"), the site named by its host. Pure.tools/presidency.test.ts
src/site/party-colours.tsPalette B2 by party abbreviation, and the colour of "Autres".By eye on the screens
src/site/ballot.tsThe ballot page: list, item page, the three tabs, the mini half-circle of recommendations. Re-renders when the territory changes.Parity run; tsc
src/site/dom.ts, main.tsSmall helpers (element lookup, HTML escaping, accent-free search, host name, Swiss date); the entry point that starts the pages.tsc
tools/cli.tsThe maintainer's commands: check (schemas, then cross checks, the Parliament and cantonal rules, the staleness notices), links, parliament, cantonal-parliaments (the download; the reading is in the modules below).Run on deliberately broken data and on a local server (redirect to a search engine, 503 then 200); parliament with a wrong key (nothing written) and check on a tampered copy
tools/cantonal-parliaments.tsWhat the command reads in the OFS workbook (the "actuel" sheet, columns, covered rows, notes), the column-to-party mapping per canton, the parliament sizes, and the rules on the generated file.tools/cantonal-parliaments.test.ts, on a workbook built in the test and on the committed file
tools/xlsx.tsA small xlsx reader on Node's built-ins: the zip container, the sheet list, shared and inline strings, each cell's text. Throws on anything it does not understand, never guesses.tools/xlsx.test.ts
tools/cantonal-governments.tsThe rules on the hand-kept governments (covered canton, size, parties of the canton) and the 180-day staleness rule shared by every hand-kept record.tools/cantonal-governments.test.ts
tools/party-presidencies.tsThe rules on the hand-kept presidencies (names present, not blank, not twice) and their staleness notice.tools/party-presidencies.test.ts
tools/build.tsBundles src/site/main.ts with esbuild as one classic script, without the maintainer-only fields (_readme, left_right, request), copies the page, styles and licence into dist/. With the Parliament's and the cantonal data, the script weighs 167 Ko on 2026-11-17.Opening dist/index.html from disk

Reused unchanged: the Confederation design system stylesheet and fonts. index.html gains the institutions page block, css/site.css its member, chart and source classes. The pure modules hold no DOM and import no JSON, so node --test loads them directly.

How it is checked

CheckWhat it provesWhere it runs
tsc on two configurationsThe site (browser types) and the tooling (Node types) compile; schemas match their interfacesnpm run check, CI
Unit tests39 tests in 7 files under tools/: the xlsx reader, the OFS reading and its rules, the cantonal card lines, the government and presidency rules, the presidency line, the members of a federal seat groupnpm test
Referential checkEvery data file matches its schema, then: unique ids and codes, known territories, url null exactly when not found, ballot recommendations only for existing national parties, every id the site links to exists, the Parliament, cantonal and presidency rules of the previous tabnpm run check, CI
Link checkCurrent URLs answer and stay on their domain (decision table in the previous tab)npm run links, CI on each push and every Monday
Screens read backThe institutions pages and the party cards, captured or read as text in headless Chromium at 390 px, match the figures of the generated files and the hand-kept recordsBy hand at each change of these screens; not automated
Parity runDuring the migration, the old site and the new dist/ were driven through the same 29 steps in headless Chromium: 27 identical renders, 2 differing only where the old script crashed on a shorter party listOnce, by hand; not automated

The pure modules that compute what a page shows are unit-tested; the code that writes the HTML is not: the screens are checked by eye, the data by the referential check.

Decisions on this layer

Settled
  • One language, TypeScript, for the site and the tooling; the tooling runs on Node 26 with no compile step.PRD-0001 §6
  • Development dependencies only: typescript, esbuild, @types/node, pinned exactly.PRD-0001 §6
  • One file of types describes the data; site and check both use it.PRD-0001 §6PRD-0001.US-09
  • No URL in the site code: links are looked up by id in the referential.PRD-0001.US-08
  • Code names in English, everything shown on the site in French.PRD-0001 §6
  • Routes, markup and behaviour are those of the site before the migration.PRD-0001 §6
  • The site and the check read the generated Parliament file through the same module, so a rule holds in both.PRD-0001.US-16
  • Party colours live in one module, keyed by the party abbreviation.PRD-0001 §8
  • The xlsx reader is written in the tool with Node's built-ins; a library only if it meets a case it cannot read.PRD-0001.US-17Research-0002, ruling 5
Left to the implementation
  • How the rendering code is split inside app.ts and ballot.ts.
  • Whether the parity run becomes an automated test.
  • Whether the bundle trims the Parliament's data further at build time.
