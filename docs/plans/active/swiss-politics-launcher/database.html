No database: five JSON files

There is no database and no server. The "tables" are five JSON files in data/, edited by hand and checked by npm run check, then copied into the script at build time. Each file wraps its content in one key, next to a free _readme note for editors. Row counts are those of 2026-11-16.

FileHoldsRows
territories.jsonThe Confederation (CH) and the 26 cantons; a canton is covered once it has parties27
parties.jsonParties per territory, left to right: the order of the array is the order on screen. 33 verified, 2 to confirm, 16 not found51
state-sites.jsonOfficial sites per territory, the canton's own site first. 14 verified, 1 to confirm15
tools.jsonDecision aids, valid for every territory. All verified7
ballot.jsonThe next ballot: 4 items, 7 sourced party recommendations, 6 cantonal entries, 3 sources1

Nested in these rows: 10 previous URLs and 18 party facts, all 18 still without a source.

Decisions on this layer

Settled
  • The data lives in one JSON file per referential, not in code.PRD-0001.US-09
  • Every link records its status, check date, evidence and previous addresses.PRD-0001.US-10
  • A canton is available as soon as it has parties in the parties file.PRD-0001.US-09
  • Facts without a source are kept in the data but not shown.PRD-0001 §8PRD-0001.US-06
  • Party recommendations exist only for national parties and only with a listed source.PRD-0001.US-03
  • The data is embedded at build time; nothing is fetched at run time.PRD-0001.US-12

  • The order of keys inside an entry and the indentation of the files.
