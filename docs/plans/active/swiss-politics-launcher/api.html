No HTTP API

The site is static: no server of its own, no account, no request to a backend. Every piece of data is inside the script at build time, so there is no OpenAPI document. What it does have are contracts: the address a voter can share, what the browser remembers, the files the build produces, the commands the maintainer runs, and the two outside APIs the maintainer's machine calls.

OFS table, as npm run cantonal-parliaments reads it

The OFS keeps one current version of each table and marks the older ones as redundant. The command asks the catalogue for that version, checks its terms, downloads the workbook and reads it with a reader written in the tool (no new dependency).

The OFS gives the year of each election, not its date: the site writes "élection de 2023". Results are those of election day; later changes of group are not counted, and the page says so.

Decisions on this layer

Settled
  • No backend, no account, no tracking; the only stored state is the territory, in the visitor's own browser.PRD-0001 §3
  • The page and territory live in the address, so a page can be shared.PRD-0001.US-05
  • The built site works from disk: one classic script with the data inside.PRD-0001.US-12PRD-0001 §6
  • A redirect to another domain fails the link check; previous URLs are never tested.PRD-0001.US-11PRD-0001.US-10
  • Refused robots and timeouts are listed for a manual check and never fail, locally or in CI.PRD-0001.US-11PRD-0001 §8
  • The data check and the link check run on every push and pull request, the link check also every Monday.PRD-0001.US-11PRD-0001.US-12
  • The federal composition comes from the new Parliament API ws.parl.ch; the legacy OData service and OpenParlData are not used.Research-0002, ruling 2PRD-0001 §8
  • The key is read from the environment or the maintainer's file and is never written to the repository, the generated file or the logs; the command runs on the maintainer's machine.PRD-0001.US-16
  • For now the key is not a CI secret: the pipeline does not refresh the federal composition, the maintainer runs the command by hand.PRD-0001 §8
  • A failed fetch, or an answer that breaks a rule above, writes nothing.PRD-0001.US-16
  • The stored request is text, not a link, so the link check never calls an API that refuses calls without a key.PRD-0001.US-11PRD-0001.US-16
  • The cantonal parliaments come from one OFS table found through its catalogue, read by a reader written in the tool; the command writes nothing when the table, its terms or its totals are not as expected.PRD-0001.US-17Research-0002, rulings 1, 5 and 6
  • Governments and presidencies are kept by hand, each with its source and check date; the check warns after 180 days and never fails on age.PRD-0001.US-18Research-0002, ruling 8
